# Contributing to stdpopsim

We welcome contributions to the species and model catalog, Python API,
documentation, and tutorials, as well as bug reports and suggestions.

Start with the [developer quickstart](https://popsim-consortium.github.io/stdpopsim-docs/latest/development.html#developer-quickstart)
for the contribution workflow, coding standards, review process, and ways to
ask for help. The full [development guide](https://popsim-consortium.github.io/stdpopsim-docs/latest/development.html)
includes installation instructions and the requirements for each type of catalog
contribution. Its source is [docs/development.rst](docs/development.rst).

Please read and follow our [Code of Conduct](CODE_OF_CONDUCT.md).
